Wi-Fi

คู่มือการใช้งานระบบ eduroam

eduroam (education roaming) คือบริการเครือข่ายไร้สายสำหรับสถาบันการศึกษาทั่วโลก เมื่อเชื่อมต่อสำเร็จที่มหาวิทยาลัยแล้ว สามารถใช้บัญชีเดิมเชื่อมต่อ Wi-Fi ในสถาบันสมาชิกอื่นได้ทันที

นักศึกษา บุคลากร SSID: eduroam

ขั้นตอนการเชื่อมต่อ

  1. เปิด Wi-Fi บนอุปกรณ์ แล้วเลือกเครือข่ายชื่อ eduroam
  2. กรอก Username เป็น รหัสนักศึกษา@rmu.ac.th
  3. กรอก Password เป็น เลขบัตรประชาชน 13 หลัก
  4. หากอุปกรณ์ถามวิธียืนยันตัวตน ให้เลือก EAP method: PEAP และ Phase-2: MSCHAPV2
  5. ช่อง CA certificate ให้เลือก ใช้ใบรับรองของระบบ (Use system certificates) และกรอก Domain / Server name เป็น rmu.ac.th — ห้ามเลือก “Do not validate” หรือ “ไม่ตรวจสอบ”
  6. กด เชื่อมต่อ (Connect) แล้วรอสถานะขึ้นว่าเชื่อมต่อแล้ว
เชื่อมต่อไม่ได้? ลบโปรไฟล์ eduroam เดิมออกจากอุปกรณ์แล้วเชื่อมต่อใหม่ ตรวจสอบว่าไม่มีช่องว่างท้าย Username และรหัสผ่านตรงกับเลขบัตรประชาชน หากยังไม่ได้ ติดต่อเจ้าหน้าที่
ห้ามปิดการตรวจสอบใบรับรอง: การเลือก “ไม่ตรวจสอบ” ทำให้ผู้ไม่หวังดีตั้ง Wi-Fi ปลอมชื่อ eduroam แล้วดักบัญชีและรหัสผ่านของท่านได้ทันที หากอุปกรณ์เชื่อมต่อไม่ได้เมื่อตั้งค่าถูกต้อง ให้ติดต่อเจ้าหน้าที่ อย่าแก้ด้วยการปิดการตรวจสอบ · แนะนำให้ติดตั้งโปรไฟล์อัตโนมัติผ่าน eduroam CAT หรือแอป geteduroam ซึ่งตั้งค่าใบรับรองให้ถูกต้องโดยไม่ต้องกรอกเอง
รหัสผ่านเริ่มต้น: เลขบัตรประชาชนเป็นข้อมูลที่ผู้อื่นอาจรู้หรือคาดเดาได้ ให้เปลี่ยนรหัสผ่านทันทีหลังเข้าใช้งานครั้งแรก ตั้งรหัสที่ไม่ซ้ำกับระบบอื่น เปิดการยืนยันตัวตนสองชั้น (MFA) หากระบบรองรับ และไม่แชร์บัญชีให้ผู้อื่น

Network

คู่มือการใช้งานระบบ VPN (RMU-SSLVPN)

VPN (Virtual Private Network) หรือเครือข่ายส่วนตัวเสมือน ใช้เทคนิค tunneling บนอินเทอร์เน็ต ทำให้ไม่ว่าอยู่ที่ใดก็เสมือนใช้งานเครือข่ายภายในมหาวิทยาลัย เข้าถึงทรัพยากรที่จำกัดเฉพาะภายในได้ เช่น ฐานข้อมูลงานวิจัยของสำนักวิทยบริการ ระบบการเรียนการสอนออนไลน์ และระบบ MIS / E-DOC

ขั้นตอนการติดตั้งและใช้งาน

  1. ดาวน์โหลดโปรแกรมที่ fortinet.com/support/product-downloads เลือกหัวข้อ FortiClient VPN ไฟล์ชื่อ FortiClientVPNOnlineInstaller.exe
  2. เปิดตัวติดตั้ง โปรแกรมจะดาวน์โหลดไฟล์เพิ่มเติม รอจนครบ 100%
  3. เลือก Yes, I have read and accept the License Agreement แล้วกด Next
  4. กด Next จนถึงปุ่ม Install แล้วรอจนติดตั้งเสร็จ กด Finish
  5. เปิดโปรแกรม เลือก I acknowledge… แล้วคลิก I accept
  6. คลิก Configure VPN แล้วกรอกค่าตามตารางด้านบนให้ครบ จากนั้นกด Save
  7. เมื่อต้องการเข้าเครือข่ายมหาวิทยาลัย ใส่ Password แล้วคลิก Connect
  8. เมื่อเลิกใช้งาน คลิก Disconnect ทุกครั้ง
รหัสผ่านเริ่มต้น: ใช้เลขบัตรประชาชนเช่นเดียวกับระบบอื่น ให้เปลี่ยนรหัสผ่านทันทีที่เข้าใช้งานได้ และอย่าเลือก “Save login” บนเครื่องที่ใช้ร่วมกับผู้อื่น
ข้อตกลงการใช้งาน: ใช้เพื่อการศึกษาค้นคว้าเท่านั้น ระบบบันทึกการใช้งานตาม พ.ร.บ. ว่าด้วยการกระทำความผิดเกี่ยวกับคอมพิวเตอร์ฯ บัญชีผู้ใช้เป็นของส่วนตัว ห้ามแจกจ่ายให้ผู้อื่น เจ้าของบัญชีต้องรับผิดชอบผลที่เกิดขึ้นแต่เพียงผู้เดียว

ลืมรหัสผ่าน — รีเซตด้วยตนเอง

  1. เข้าหน้าลงชื่อเข้าใช้ที่ office.com (Microsoft) หรือ google.com (Google)
  2. คลิก “ลืมรหัสผ่าน” หรือ “Forgot password” ใต้ช่องกรอกรหัสผ่าน
  3. กรอก Username แล้วเลือกยืนยันตัวตนผ่านอีเมลสำรอง หรือ SMS เบอร์โทรที่ลงทะเบียนไว้
  4. กรอกรหัส OTP ที่ได้รับ แล้วตั้งรหัสผ่านใหม่
ยังรีเซตเองไม่ได้? แจ้งขอรีเซตรหัสผ่านออนไลน์ที่ ccservice.rmu.ac.th — ระบบนี้ต้องเข้าสู่ระบบก่อนจึงจะแจ้งเรื่องได้ หากเข้าสู่ระบบไม่ได้เลย ให้ติดต่อเจ้าหน้าที่ศูนย์เทคโนโลยีดิจิทัลและนวัตกรรมโดยตรง พร้อมแสดงบัตรนักศึกษาหรือบัตรประชาชนเพื่อยืนยันตัวตน
ระยะเวลาดำเนินการที่ศูนย์ฯ ประกาศไว้คือ 3–4 ชั่วโมงในวันและเวลาราชการ อาจล่าช้ากว่านี้ในช่วงที่มีผู้ใช้บริการจำนวนมาก
กันปัญหาไว้ก่อน: หลังเข้าสู่ระบบครั้งแรก ให้ลงทะเบียนอีเมลสำรองและเบอร์โทรศัพท์ทันที จะรีเซตรหัสผ่านเองได้โดยไม่ต้องรอเจ้าหน้าที่
