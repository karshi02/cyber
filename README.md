# Cyber Security RMU — เว็บไซต์ประชาสัมพันธ์

Static site ล้วน (HTML/CSS/JS ไม่มี build step ไม่มี backend) ของหน่วยงานความมั่นคงปลอดภัยไซเบอร์ มหาวิทยาลัยราชภัฏมหาสารคาม

## โครงสร้างไฟล์

```
index.html          หน้าแรก: hero / บริการ / คู่มือ / เกี่ยวกับเรา / แจ้งเหตุ / อบรม / ติดต่อ
team.html           ผังโครงสร้างบุคลากร (การ์ดกดเปิด modal)
guides.html         คู่มือ: eduroam, VPN, อีเมล, Authentication Gateway
favicon.svg         โลโก้ ใช้เป็น favicon + โลโก้บน header
robots.txt          ชี้ไป sitemap
sitemap.xml         รายการ 3 หน้า
assets/
  style.css         ธีมหลัก + layout + header/footer (ใช้ทุกหน้า)
  components.css    hero ย่อย, การ์ดบุคลากร, modal, คู่มือ, intro overlay
  org.css           ผังองค์กรหน้า team
  theme.css         สวิตช์ธีม + โทนสีโหมดมืด
  main.js           theme switch, intro, เมนูมือถือ, typewriter, modal บุคลากร, scrollspy
imgs/               รูปบุคลากร
```

## Deploy

คัดลอกทั้งโฟลเดอร์ขึ้น web root ได้เลย ไม่ต้อง build ไม่ต้องติดตั้งอะไร

ปัจจุบัน deploy บน **GitHub Pages** → https://karshi02.github.io/cyber/ (branch `main`, โฟลเดอร์ root) push ขึ้น `main` แล้ว Pages build ใหม่เองภายใน ~1 นาที

ถ้าย้ายไปโดเมนมหาวิทยาลัย ต้องแก้ URL `https://karshi02.github.io/cyber/` ทุกจุดต่อไปนี้:

- `<link rel="canonical">` และ `og:url` / `og:image` ในทั้ง 3 หน้า
- `robots.txt` (บรรทัด Sitemap)
- `sitemap.xml` (ทุก `<loc>`)
- JSON-LD ท้าย `<head>` ของ `index.html`

## รอบทบทวนเนื้อหา

คู่มือใน `guides.html` อ้างค่าจริงของระบบ (โดเมน พอร์ต รูปแบบ username) **ทบทวนอย่างน้อยภาคเรียนละครั้ง** และทุกครั้งที่ศูนย์เทคโนโลยีดิจิทัลและนวัตกรรมเปลี่ยนระบบ

แหล่งอ้างอิงต้นทาง:
- อีเมล — https://cc.rmu.ac.th/email-rmu/
- Authentication Gateway — https://cc.rmu.ac.th/authentication-gateway/
- VPN — คู่มือ RMU-SSLVPN (Google Doc ของศูนย์ฯ)

## หลักการที่ห้ามละเมิดเวลาแก้คู่มือ

- **ห้าม**เขียนแนะนำให้ปิดการตรวจสอบใบรับรอง (`Do not validate` / ไม่ตรวจสอบ) ในคู่มือ Wi-Fi เด็ดขาด เปิดช่องให้ตั้ง Wi-Fi ปลอมดักบัญชีได้
- รหัสผ่านเริ่มต้นเป็นเลขบัตรประชาชน ทุกคู่มือที่กล่าวถึงต้องมีคำเตือนให้เปลี่ยนรหัสทันที
- ห้ามใส่รหัสผ่าน เลขบัตรประชาชนจริง หรือข้อมูลส่วนบุคคลลงในหน้าเว็บ

## หมายเหตุทางเทคนิค

- Intro animation เล่น**ทุกครั้งที่โหลดหน้า** (ตามที่เจ้าของงานเลือกไว้) ข้ามได้ด้วยการคลิกหรือกดปุ่มใดก็ได้ และมี hard stop กันค้าง (index 2.6 วิ / gate 3 วิ)
- ธีม light/dark เก็บใน `localStorage` คีย์ `theme` ตั้งค่าก่อน paint ด้วย inline script ใน `<head>` ของทุกหน้า
- ทุก animation เคารพ `prefers-reduced-motion: reduce`
- รูปยังเป็น JPG/PNG ขนาดเต็ม ถ้าต้องการเร็วขึ้นให้แปลงเป็น WebP และย่อเหลือ ~400px
